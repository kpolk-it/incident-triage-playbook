# Incident Triage Playbook

A practical reference for performing initial triage, documentation, and escalation of security and technical incidents.

This repository is designed to support consistent, high-quality incident handling — especially useful for SOC Tier 1, security operations, and escalation support roles.

## Purpose

- Standardize the initial triage process
- Improve quality of documentation and handoffs
- Reduce missed details during escalation
- Provide reusable templates for real-world use

## How This Relates to SOC Work

This playbook mirrors core Tier 1 SOC and security operations activities:

- Performing initial alert and ticket triage
- Gathering context and evidence
- Determining whether an issue can be resolved or needs escalation
- Creating clear, consistent documentation and handoffs

These skills are foundational for roles such as Cyber Security Analyst, SOC Analyst, and security operations support positions.

## Contents

- **Triage Checklist** – Step-by-step guide for initial alert/ticket review
- **Escalation Guide** – When and how to escalate
- **Incident Report Template** – Structured documentation format
- **Examples** – Sample walkthroughs of common scenarios (suspicious login, malware, phishing, failed login spike)
- **Templates** – Ready-to-use notes and handoff formats
- **Scripts** – Simple PowerShell helper for collecting basic endpoint information during triage
## Who This Is For

- Aspiring SOC / Cyber Security Analysts
- IT professionals moving into security operations
- Anyone responsible for ticket triage and escalation in a regulated environment

## How to Use

1. Start with the [Triage Checklist](docs/triage-checklist.md)
2. Document findings using the templates
3. Follow the escalation criteria when needed
4. Review the examples for reference
